Top-level frontmatter keys SkillMeta models as named fields. Anything else is an unknown/namespaced key (e.g. another tool’s coact: block) and is kept verbatim in SkillMeta.extra so it survives a parse→render round-trip.

class skill.base.SkillMeta(name, description, audience=None, license=None, compatibility=None, metadata=<factory>, allowed_tools=<factory>, extra=<factory>)[source]¶

Bases: object

Parsed YAML frontmatter from a SKILL.md file.

>>> m = SkillMeta(name='test', description='A test skill')
>>> m.name
'test'

Unknown/namespaced top-level keys are preserved in extra and re-emitted on render, so a tool’s additive frontmatter block isn’t silently dropped:

>>> m = SkillMeta(name='t', description='d', extra={'coact': {'model': 'sonnet'}})
>>> m.to_dict()['coact']
{'model': 'sonnet'}
extra: dict[str, Any]¶

Unknown/namespaced top-level frontmatter keys, kept verbatim for round-trip.
